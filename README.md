# Economic Research

(최종 목표)
관심있는 기업들과 그 기업들과 관련되어 있는 기업들의 정보를 자동으로 수집하고  정리 요약하는 프로그램

## 왜 만들었나
뉴스나 공시를 매일 보기 힘들고 시시각각 변하는 경제 시장을 보기 편하게 하고 싶어서

## v1.0에서 할 수 있는 것
기업 이름을 입력하면 그 기업에 관련된 기사가 자동으로 정리된다.

## 실행 방법
1. Python을 설치한다.
2. 저장소 전체를 받아야 한다(GitHub의 초록색 Code 버튼 Download ZIP, 또는 git clone).
3. 가상환경을 만들고 켠 다음, 필요한 라이브러리를 설치한다.
```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
4. 결과를 저장할 output 폴더를 만든다.
```
mkdir output
```
5. 프로그램을 실행한다.
```
python src/main.py
```
6. 터미널 입력란에 조사하고 싶은 기업을 입력한다.

## 결과 예시
output 폴더에  알고싶은 기업.csv 가 만들어진다(output/삼성전자_2026-11-25.csv).
그 파일안에는 발행 시간, 발행한 곳, 제목 순으로 칸이 나누어져 있다.

## 알려진 한계
1. 아직 구글에 올라온 뉴스만을 분류하여 저장한다.
2. 자동화가 덜 구현되어 직접 써야 한다(알고 싶은 기업명을 일일히 입력해야 한다).
3. 분류된 파일안에 정보(기사의 본문등)가 아직 부족하다.
4. 검색 결과를 거르지 않고 그대로 저장하여 관련 없는 기사가 섞일 수 있다.
